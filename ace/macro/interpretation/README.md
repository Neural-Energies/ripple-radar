# Macro interpretation

This is the system map and the rules for extending it. It is not a model, and it does not emit forecasts.

- `SKILL.md` — what to extend, and what must not be invented
- `references/current-system.md` — what Ripple already has
- `references/gap-and-reuse.md` — what is missing, and which outside repos are allowed
- `references/schemas.md` — the objects the first US slice must emit
- `references/validation.md` — the tests those objects have to pass
